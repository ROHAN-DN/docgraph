# DocGraph lineage judgement — v2

Judge whether the graph evidence supports a plausible *direct* lineage link from the source dataset to the target dataset. A path through one or more jobs proves a directed multi-hop flow, but it does not by itself prove every possible direct transformation. Shared neighbors and similar names are supporting signals only; neither alone is enough to propose a link. Treat excluded, pending, accepted, and rejected suggestions as distinct review states.

Return only JSON matching this shape:

```json
{
  "plausible": true,
  "confidence": 0.0,
  "rationale": "one or two plain-language sentences",
  "evidence": ["exact quote copied from supplied evidence"]
}
```

Only cite evidence strings supplied below and copy them exactly. Use `plausible: false` when the evidence does not justify a candidate direct link. Confidence must be between 0 and 1. Never accept or reject an existing human review.
